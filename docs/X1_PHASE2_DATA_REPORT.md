## 4. 各活动类的可达上限（物理边界，未放水）

- **跑步（CMU 09/10）**：几乎全灭（12 段 run + 1 段过窗 jog 中仅 6 段慢跑过门）。失败主导：腕误差
  （跑步摆臂快，5-tap 平滑滞后 + 肩锥均衡使方向误差超限）与胸向/扭转（腾空相骨盆俯仰大）。
  这是当前重定向管线的物理边界，不是门限过严：锚定臂距带 [0.244, 0.308] m 是 X1 臂几何硬约束。
- **舞蹈（05/60/131/135/136/137/143）**：84+ 候选仅 27 过门（过头臂、深蹲、地面动作导致腕误差/倾角/扭转超限）。
- **转身**：151/244 过门（净偏航口径下）。
- **行走**：289/466 过门——最稳的类别。

按契约（用户修订指令 #3）：330 段净入库目标在诚实门限下不可达，实收 **289 段训练库**（27.2 min，
为一阶段 2.06 min 库的 13 倍、多样性从单一行走扩展到 4 类活动、45 个 subject），报告如实记录。
