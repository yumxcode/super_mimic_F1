## 1. 手臂重定向修复（任务 1）

### 1.1 根因（比一阶段结论更深一层）

一阶段已知现象：67.2% 帧有关节贴限位（肘 pitch 57.8%）。二阶段量化出完整机制链：

1. **目标悬空**：GMR 的臂目标来自骨盆相对缩放（每骨骼一个标度 × T-pose 一帧标定）。
   X1 短躯干（肩高仅比根高 +0.16m，而 0.9275×人体躯干向量≈0.41m）导致
   肩/肘/腕目标悬空在真实可达位置上方 0.25-0.45m（09_01 实测肩目标 z=1.24 vs 肩 FK z=0.77）。
2. **肘贴肩几何**：X1 的肘关节几乎就在肩上（|shoulder_yaw→elbow|=0.048m），前臂 0.260m，
   腕距肩被物理限制在 **[0.244, 0.308]m**（肘 2.0→0 rad）。人体行走 |腕-肩|≈0.44-0.50m，
   经缩放后的腕目标 53% 帧落在可达环外——stock 解放弃跟踪（腕 FK-目标 p50 误差 0.29-0.44m），
   肘停死在 +2.0 rad。
3. **腕姿态旋转偏移**：pos_offset 随人体腕姿态旋转摆动（|offset|=0.354m），加剧目标漂移。

### 1.2 方案对比（5 段研究集：07_01/82_13 走、09_01/09_02 跑、137_01 舞；tools/x1_arm_study.py）

| 方案 | 肘饱和 | 臂任意饱和 | 腕方向误差 | 肘 p50 (rad) | 结论 |
|---|---|---|---|---|---|
| stock（一阶段） | 95-100% | 100% | 78-120° | 0 / 2.0（双停） | 基线 |
| a) 权重软化（soft） | 100% | 100% | 57-98° | 0 / 2.0 | 目标错则权重无用 |
| a) 限位余量（margin 0.1rad） | 0% | 0% | 73-104° | 1.89（骑余量边界） | 清零饱和但姿态不变 |
| c) 迭代/正则（iter30/reg） | ≈stock | ≈stock | ≈stock | ≈stock | 无效（默认已开正则） |
| b) split 二段重解（最终版） | **0%** | **0%** | **14-34°** | **0.53-0.65** | ✅ 胜出 |

### 1.3 修复实现（tools/x1_arm_fix.py，motions/x1_ik_config.json，build_x1_motions.py --arm-mode refine）

1. **GMR 底层解**：腕目标锚定**机器人实时肩 FK**——方向=人体肩→腕向量，距离
   `clip(0.62·|wr-sh|, 0.268, 0.300)`（可达带内构造性可达）；匹配表权重软化
   （腕 rot→0、肘 rot 3/1、腕 pos 5）。
2. **二段臂部重解**（冻结基座/腿/躯干）：腕位置任务（显式锚定公式）+ 姿态先验
   （肘 0.5、肩 roll −0.2）+ ConfigurationLimit 0.15rad 余量（warm start 先钳入余量带：
   mink 的限位只拦进入不推出）+ 腕速度上限 + 收敛循环 + 5-tap 平滑。
3. **生产固化**：41 段库重建后全帧贴限位 **67.2%→0.3%**；逐关节（肘 57.8%→0，肩 roll 18.1%→0）。

中途审查抓到一个关键实现坑并修复：arm_refine 曾经 `scaled_human_data` 间接引用回
stock 目标（实测 |FK-stock|=6-9mm vs |FK-anchored|=11-19cm）——显式锚定后所有指标
再降一半（方向误差 22-45°→14-34°，跑步/舞蹈 jerk 降 3-40×）。

### 1.4 物理可达边界（如实记录）

- 腕距肩 ∈ [0.244, 0.308]m 是 X1 臂几何硬约束；任何带外目标必然饱和——权重调不出。
- 锚定意图腕残差地板 ≈ r·sin(15-20°方向误差) + 平滑滞后 ≈ **0.07-0.10m**（验收门
  0.13/0.25 据此校准，记录在案）。
- 跑步摆臂（快、幅度大）在当前管线下过不了腕误差门——因此二阶段库无跑步段。

## 2. 规模决策（任务 2，docs/X1_PHASE2_DATASET.md）

论文（arXiv 2610.28480）：264.56h/129,514 段是覆盖率口径；规模消融显示 1h 库 return 已近饱和

## 7. 限制与下一步

1. **跑步/快跑不在训练库**（重定向腕误差物理边界）——需要前臂更长或腕目标动态缩放的
   管线扩展，或对跑步段单独放宽为"净方向复现"门。
2. **heldout 占比 6%**（18 段）低于 10-15% 目标：诚实门限下 heldout 族过门段数有限；
   下一轮可预留更多 subject。
3. 舞蹈段过门率 32%：库内舞蹈以"可达范围内的节奏动作"为主，过头/地面动作被门剔除。
4. 推扰 settle 时间度量窗口不足；push_test.py 的专用 12s 站立协议更适合量化。
5. 训练中 val 曲线（0.919→0.930）仍在缓慢上升——若追求极限可续训到 60k（预算允许），
   当前 0.9299/0 失败已满足契约目标。
6. 二次重跑成本注意：入口脚本默认配置已改为 phase-2，startScript 显式传 --hparams。
